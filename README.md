# Lumina — Sabiduría Interior

Single-page landing for **Lumina**, a mindfulness / inner-wisdom concept.
Lightweight, responsive, and built with vanilla HTML, CSS and JavaScript.

<!-- 📸 Tip: add a screenshot here → ![Lumina](screenshot.png) -->

## 🛠️ Tech stack
`HTML` · `CSS` · `JavaScript`

## 🚀 Run locally
Open `index.html` in a browser, or serve it:
```bash
python -m http.server 8080
# then open http://localhost:8080
```
